## Exercise Descriptions

### modify_hangman.py

A simple implementation of the classic Hangman game. The player guesses letters to try to figure out a hidden word before running out of attempts.

### csv_movies.py

A script that writes a list of movie titles to a CSV file using Python's `csv` module.

### create_a_module.py

Demonstrates how to create and use a custom module in Python. The script imports a function from another module and uses it within the main function.

### type_a_number.py

A script that prompts the user to type a number and converts the input to an integer. It includes error handling to manage invalid inputs.

### guess_a_number.py

A number guessing game where the user tries to guess a number from a predefined list. The game continues until the user decides to quit.

### try_inheritance.py

Illustrates the concept of inheritance in Python by defining a base class `Shape` and derived classes `Rectangle` and `Square`. Each derived class includes methods for calculating the perimeter and other functionalities.

### algorithms_challenge.py

Contains a function to solve a common algorithmic problem: finding the single number in a list where every element appears twice except for one.
