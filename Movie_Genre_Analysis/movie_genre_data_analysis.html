Movie Genre Data Analysis¶

This notebook focuses on analyzing movie genres using the IMDb movies dataset. We will explore various aspects of genres, including their frequency, budget, revenue, popularity, and voting averages.

Research Questions¶

  1. Which genres are the most common (number of movies made)?
  2. Which genres have high average budget and revenue?
  3. Which genres have high average popularity?
  4. Which genres have the highest number of movies with a voting average >= 8?

Research Hypotheses¶

  1. The best movies according to vote average return high profit and revenue.
  2. The best movies according to popularity return high profit and revenue.
  3. Highly budgeted movies return high revenue and profit.
  4. Highly budgeted movies have high popularity.

Acknowledgements¶

This analysis is based on the IMDb movies dataset provided by AnalystBuilder's Pandas for Data Analysis course. The CSV file used is 'imdb_movies.csv'.

# Data Preparation

# Split the genres and create a new DataFrame
genres_expanded = df['genres'].str.split('|', expand=True).stack().reset_index(level=1, drop=True)
genres_expanded.name = 'genre'
df_genres = df.drop('genres', axis=1).join(genres_expanded)

# Calculate the average budget and revenue for each genre
average_budget_revenue = df_genres.groupby('genre')[['budget', 'revenue']].mean().reset_index()

# Display the top genres by average budget and revenue
average_budget_revenue_sorted = average_budget_revenue.sort_values(by=['budget', 'revenue'], ascending=False)
