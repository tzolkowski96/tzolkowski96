#### 2. US Household Income Analysis
- **Objective**: Transform messy demographic data into clear economic insights through careful cleaning and statistical analysis
- **Technologies**: MySQL 8.0+, MySQL Workbench, Git
- **Dataset**: 32,533 location records and 32,526 statistics records across all 50 US states
- **Key Achievements**:
  - Achieved exceptional 9.62/10 data quality score through systematic validation
  - Uncovered 30% income gap between Northeast ($102,068) and Southeast ($71,307) regions
  - Identified patterns of income inequality through mean-to-median ratio analysis
  - Developed advanced SQL techniques including weighted quality scoring system
- **Technical Highlights**:
  ```sql
  -- Calculate quality score based on weighted factors
  WITH quality_metrics AS (
      SELECT
          -- Calculate quality percentage for Place values (25% weight)
          (1 - (SUM(CASE WHEN Place IS NULL OR TRIM(Place) = '' THEN 1 ELSE 0 END) / COUNT(*))) * 25 AS place_quality,
          -- Calculate quality percentage for ZIP codes (35% weight)
          (1 - (SUM(CASE WHEN invalid_zip_code = TRUE THEN 1 ELSE 0 END) / COUNT(*))) * 35 AS zip_quality,
          -- Calculate quality percentage for coordinates (40% weight) - highest importance
          (1 - (SUM(CASE WHEN invalid_coordinates = TRUE THEN 1 ELSE 0 END) / COUNT(*))) * 40 AS coord_quality
      FROM USHouseholdIncome_Clean
  )
  SELECT
      'Enhanced Data Quality Score' AS metric,
      ROUND((place_quality + zip_quality + coord_quality) / 10, 2) AS score_out_of_10
  FROM quality_metrics;
  ```
- **Skills Demonstrated**:
  - Advanced SQL: Window Functions, CTEs, Dynamic SQL, Stored Procedures, Transaction Management
  - Data Engineering: Quality Scoring, Systematic Data Cleaning, Error Logging
  - Statistical Analysis: Outlier Detection, Percentile Calculations, Geographic Segmentation
  - Performance Optimization: Strategic Indexing, Query Tuning, Resource Management
- **Impact**:
  - Revealed clear prosperity gradient from coastal to interior regions
  - Identified communities with high income inequality (mean-to-median ratios exceeding 3.65)
  - Provided data-driven insights for economic development strategies
